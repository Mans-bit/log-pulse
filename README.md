# Log-Pulse: Распределенная система мониторинга логов и здоровья серверов

Легковесный микросервис для отслеживания системных метрик и состояния серверов в реальном времени, написанный на языке **Go (Golang)**.

## Ключевые особенности
* **Ноль внешних зависимостей:** Проект написан строго на стандартной библиотеке Go (`runtime`, `net/http`), что обеспечивает максимальную безопасность и скорость работы.
* **Высокая производительность:** Прямое обращение к низкоуровневой статистике рантайма Go обеспечивает практически нулевую нагрузку на процессор (CPU).
* **Микросервисная архитектура:** Метрики отдаются в стандартном формате JSON, что позволяет легко интегрировать сервис с Prometheus, Grafana или любым веб-интерфейсом.

## Спецификация API
* **Эндпоинт (Ссылка):** `GET /api/v1/status`
* **Формат данных:** `application/json`

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com
cd log-pulse
```

2. Запустите приложение:
```bash
go run main.go
```

3. Откройте в браузере страницу с метриками:
```text
http://localhost:8080/api/v1/status
```
